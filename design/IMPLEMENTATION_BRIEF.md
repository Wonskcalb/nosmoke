## Characters (Shared/Characters/*.swift)
Public APIs (fixed — screens already call them, keep the signatures):
- `SuperPatchView(mood: .sleeping | .flying | .tired, autoplay: Bool = false, idle: Bool = false)` — viewBox 220×150
- `MicroView(count: Int, cap: Int = 12, autoplay: Bool = false)` — viewBox 160×200
- `CravingCloud(level: 0...4, autoplay: Bool = false)` — 0 Légère … 4 Très forte, viewBox 120×82
- `PlantView(stage: 0...4, autoplay:)` 120×136 · `PiggyView(autoplay:)` 130×100 · `LungsView(level: 0...1, autoplay:)` 140×106
Each view sizes itself with `.aspectRatio(w/h, contentMode: .fit)` and fills whatever frame the screen gives it.
Shared helpers in `CharacterKit.swift`: `.replayOnTap(autoplay:trigger:)` (tap increments trigger; autoplay fires once on appear unless Reduce Motion) and `ViewBox` (maps SVG coordinates to the view).

Animation rules (user requirements, non-negotiable):
- Short (≤1.5 s), plays ONCE, then rests in a still final pose identical to the static drawing. Tap replays. Only autoplay when `autoplay == true`. Respect `accessibilityReduceMotion`.
- Organic, never rigid: limbs and capes are curved paths whose control points animate (use a custom `Shape` with `animatableData`, or `KeyframeAnimator` driving point values into a `Canvas`/`Path`). Squash & stretch with anchor at the ground contact, anticipation, spring overshoot (`.spring` / `KeyframeAnimator` `SpringKeyframe`), staggered delays 30–80 ms between body → head → limbs → props, follow-through.
- The only continuous loop: Super-patch `.flying` with `idle: true` (3 faint speed lines sliding left behind it + ≤1.5pt hover bob on a ~3.2 s cycle + subtle cape ripple ~3.6 s), via `TimelineView(.animation)` or `phaseAnimator`. Disabled under Reduce Motion.
- Port the mockup's SVG coordinates and keyframe values literally (they are in the JS: `limb([...])` frames are quadratic curves `[x0,y0,cx,cy,x1,y1]`, `keyTimes` strings, durations, delays). Translate SVG path strings into `Path` calls carefully; stroke width 2 in viewBox units, round caps/joins.
